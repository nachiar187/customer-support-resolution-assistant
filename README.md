# Customer Support Resolution Assistant (Broadband & Mobile)

An AI-powered resolution assistant that processes broadband and mobile support tickets, grounds responses in local support articles, and escalates unresolved/complex cases with concise summaries.

## Setup & Run
1. Set Gemini API Key:
   export GEMINI_API_KEY="your-api-key"

2. Install dependencies & launch app:
   pip install -r requirements.txt
   python app.py
